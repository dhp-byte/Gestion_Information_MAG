## 🚀 Installation & Lancement

### 1. Prérequis
- Python 3.9 ou supérieur installé
- pip (gestionnaire de paquets Python)

### 2. Installation des dépendances
Ouvrez un terminal dans le dossier du projet et exécutez :

```bash
pip install -r requirements.txt
```

### 3. Lancement de l'application
```bash
streamlit run app.py
```

L'application s'ouvrira automatiquement dans votre navigateur à l'adresse :
👉 http://localhost:8501

---

## 📋 Fonctionnalités

| Module | Description |
|--------|-------------|
| 🏠 Tableau de Bord | KPIs opérationnels, graphiques mensuels, analyse par province |
| 📥 Collecte & Import | Import CSV/Excel (Kobo, ODK, Survey123), saisie manuelle |
| 🔍 Contrôle Qualité | Détection automatique des erreurs, score qualité, doublons |
| 🗺️ Carte Interactive | Marqueurs, clusters, HeatMap – contexte déminage Tchad |
| 📊 Analyse & Rapports | Tendances, performance équipes, statistiques descriptives |
| 📄 Export Rapport | Génération automatique de rapport Word téléchargeable |

---

## 🛠️ Technologies utilisées
- **Streamlit** – Interface web interactive
- **Pandas / NumPy** – Manipulation et analyse des données
- **Plotly** – Visualisations interactives
- **Folium / streamlit-folium** – Cartographie interactive
- **Python-docx** – Export Word automatique
- **KoboToolbox API / ODK** – Compatible avec les formats de collecte MAG
